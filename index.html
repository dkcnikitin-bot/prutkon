Облачная Синхронизация

Инструкция по подключению:

1. Зарегистрируйтесь на Firebase.
2. Создайте новый проект "Пруткон ERP".
3. Перейдите в Realtime Database и нажмите "Create Database". Выберите сервер (Европа) и тестовый режим.
4. Скопируйте URL базы выше. Скопируйте ключи API из Project Settings.
5. Система автоматически начнет фоновую выгрузку массивов orders, dbEmployees и dbSalArchive.
